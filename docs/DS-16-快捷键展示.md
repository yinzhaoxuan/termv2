# DS-16 快捷键展示（D5）

日期：2026-11-04
基线：DS-15 之后
出处：`REVIEW.md` §3 表「快捷键配置界面：v0.1 只读展示，编辑放 v0.2+」、§8 D5；`docs/TODO.md` §2.2。

## 0. 现状

- 快捷键只在 `settings.json` 的 `keybindings` 里（动作 ID → 快捷键文本），缺省动作由 `kDefaults` 补齐。启动时读一次，改文件要重启。
- `runAction`（`main.cpp`）处理的动作：`newTab closePane splitVertical splitHorizontal nextTab prevTab moveTabLeft moveTabRight focusPane copy paste pasteCtrlV pasteShiftInsert copyOrInterrupt searchHistory searchConnections chooseFont`，加上 `fontSizeFor` 处理的 `fontBigger fontSmaller fontReset`、`scrollCommandFor` 处理的 `scrollPageUp scrollPageDown scrollLineUp scrollLineDown scrollToTop scrollToBottom`。`chooseFont` 没有默认快捷键。
- 另有不可配置的键：会话树里 Enter / 双击（连接）、F2（编辑 / 重命名）、Delete（删除）、Shift+F10 / 菜单键（右键菜单）；终端里 Shift+拖动（程序开了鼠标上报时强制本地选择）。
- 用户看不到这些。空字符串表示不绑定（ADR-004），冲突在保存时才报。

## 1. 目标与边界

做：系统菜单「快捷键…」打开只读列表，列出全部可配置动作（中文名、当前快捷键、状态）与固定按键；说明怎么改；按钮打开配置目录。

不做：编辑（v0.2+，F-4）；重新加载 settings.json；在其他菜单项后面显示快捷键提示。

## 2. 模型（`uicfg`，`ui/include/uicfg/keybinding_view.h` 新文件）

```cpp
enum class BindingState { Default, Changed, Unbound, Conflict, Invalid, UnknownAction };
struct KeybindingRow {
  std::string action;     // 动作 ID
  std::string label;      // 中文名，如「新建标签」；未知动作 = 动作 ID 本身
  std::string chord;      // 显示文本；未绑定为空
  BindingState state;
  std::string note;       // 状态说明：「默认」「已修改（默认 Ctrl+Shift+T）」「未绑定」「与 copy 冲突」「无法识别的快捷键」「未知动作（忽略）」
};
// 顺序：已知动作按表内固定顺序（标签 / 窗格 / 剪贴板 / 搜索 / 字体 / 滚动），之后是文件里的未知动作（按 ID 排序）。
std::vector<KeybindingRow> keybindingRows(const SettingsFile&);
struct FixedKey { std::string keys, label; };
const std::vector<FixedKey>& fixedKeys();   // §0 列出的不可配置按键
```

- 中文名表放在 `keybinding_view.cpp`，覆盖 §0 的全部 26 个动作（25 个有默认快捷键，`chooseFont` 默认不绑定）。`focusPane` 的快捷键显示为「Alt+方向键」（存储值 `Alt+Arrow`）。
- 状态判定顺序：未知动作 → 空串（未绑定）→ `parseChord` 失败（无法识别）→ 与其他动作同一快捷键（冲突，note 写出对方的中文名；两个都标冲突）→ 与默认不同（已修改）→ 默认。冲突判定与 `validateSettings` 一致（空串不参与）。
- 需要一个测试钩子保证中文名表与默认表一致：`kDefaults` 里的每个动作在名表里都有名字（测试遍历 `defaultSettings().keybindings` 断言 `label != action`）。

## 3. 界面

- 系统菜单「导出诊断包…」之前加「快捷键…」。
- 对话框 `IDD_KEYBINDINGS`（`.rc` 与 `resource.h`）：顶部说明「快捷键在 settings.json 的 keybindings 中修改，设为 "" 表示不绑定；重启后生效。」；中间 ListView（`SysListView32`，`LVS_REPORT | LVS_SINGLESEL | LVS_NOSORTHEADER`，整行选择），三列「功能」「快捷键」「状态」；下方静态文本列固定按键（每行「键 — 说明」）；底部「打开配置目录」「关闭」。
- 「打开配置目录」：`ShellExecuteW(nullptr, L"open", configDir, …)`。
- 对话框代码放 `ui/shell_win32/keybinding_dialog.{h,cpp}`，接口 `void runKeybindingDialog(HWND, HINSTANCE, const std::vector<uicfg::KeybindingRow>&, const std::vector<uicfg::FixedKey>&, const std::filesystem::path& configDir)`。
- `InitCommonControlsEx` 加 `ICC_LISTVIEW_CLASSES`。
- 列宽按对话框宽度在 `WM_INITDIALOG` 里设（`LVM_SETCOLUMNWIDTH`，最后一列 `LVSCW_AUTOSIZE_USEHEADER`）。

## 4. 测试

- `keybindingRows`：默认设置 26 行、顺序固定：有默认值的 25 个为 Default，`chooseFont` 为 Unbound；改一个 → Changed 且 note 含默认值；`""` → Unbound；`"Ctrl+Bogus+"` 之类 → Invalid；两个动作同键 → 两行 Conflict、note 互指；未知动作排在最后；`focusPane` 显示「Alt+方向键」。
- 名表覆盖默认表（§2 末条）。
- `fixedKeys` 非空，含 F2、Delete。

Windows 手测：菜单打开、列表完整、改过 settings.json 后状态正确、按钮打开目录；150% DPI 不裁切；CI `mingw` 通过。
